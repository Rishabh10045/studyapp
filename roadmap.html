    Consistent hashing

    Hash ring

    NodeKey

    How it works

    • Hash nodes and keys onto the same ring
    • A key belongs to the first node clockwise from it
    • Remove Node B and only k1 and k4 move, to Node C
    • Add a node and it takes keys only from its clockwise neighbour
    • Virtual nodes give each server many ring positions for even load
