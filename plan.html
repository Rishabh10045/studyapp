How to use this plan

  1. Do the blocks in order and keep to the timer.
    An unfinished DSA problem goes on a "flagged" list for the weekly revision; don't let it eat the lesson block.
  2. If a lesson shows "not written yet", swap it.
    Java and Spring lessons are still being written in this order. Do the next ready lesson and come back.
  3. Only 3 hours on a weekday?
    Cut DSA to 45 minutes and drop the interview-questions block. Never drop hands-on coding.
  4. Fell behind?
    Use the weekend notes block to catch up. In week 4, mocks and the Spring AI project matter more than finishing every lesson.
